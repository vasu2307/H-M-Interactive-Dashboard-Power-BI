# H-M-Interactive-Dashboard-Power-BI
An H&amp;M-themed, multi-page Power BI report that works like a mini e-commerce storefront. It focuses on UI/UX design, page navigation and interactivity inside Power BI.
## Overview
The report recreates the look and feel of the H&M India online store. A landing
page leads the user into a product showcase page with category navigation.

## Pages
**1. Landing page**
- H&M branding and the tagline "New season, new you. Let's get dressed!"
- "Explore Now" button using Power BI page navigation

**2. Product showcase page**
- Category navigation bar: Ladies, Men, Kids, Home and Beauty
- Hero banner images for new arrivals and seasonal trends
- A row of 7 featured products, each linked to its H&M product page
- Customer rating badge (3.6 ⭐)

## Features
- Page navigation buttons
- Clickable images and buttons with web URL actions
- Custom shapes, fonts and layout on a 1280×720 canvas
- Power BI theme: CY26SU07

## Tools Used
- Microsoft Power BI Desktop
- Image assets (AVIF) from hm.com

## How to Use
1. Download `h_m_powerbi_project.pbix`
2. Open it in Power BI Desktop
3. Click **Explore Now**, then use the category buttons and product images

## Conclusion
This project shows how Power BI can be used beyond standard charts to build
a branded, interactive, storefront-style experience. It combines custom
layouts, page navigation, clickable product images and web links to guide the
user from a landing page to a product showcase.

**Key takeaways**
- Power BI's shapes, buttons and actions can produce polished, web-like UI.
- Clear navigation (Explore Now, category tabs) makes a report easier to use.
- Linking visuals to live product pages ties the report to real-world content.

**Limitations and future work**
- The report is currently design-focused and has no underlying dataset.
- Next steps: load H&M sales or transaction data (for example the Kaggle
  H&M Personalized Fashion Recommendations dataset) and add KPIs, revenue
  trends, category and product performance, customer segments and slicers.
